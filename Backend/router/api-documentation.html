POST /api/login เข้าสู่ระบบสำหรับเจ้าหน้าที่ระดับเว็บ (Admin / Staff)
PUBLIC
รายละเอียดการทำงาน

ตรวจสอบสิทธิ์ผู้ใช้งานฝั่งเว็บ หากเข้าสู่ระบบสำเร็จจะได้รับ JWT Token ที่มีอายุ 1 ชั่วโมง (กำหนดผ่าน .env) บัญชีระดับ `field_staff` จะถูกปฏิเสธสิทธิ์ในขั้นตอนนี้

Request Body (JSON)
{
  "username": "admin1",
  "password": "123"
}
Response Example
{
  "token": "...",
  "role": "admin",
  "username": "admin1"
}

GET /api/payments/receipt/:invoice_id ดึงข้อมูลใบเสร็จรับเงินเพื่อนำมาพิมพ์หรือบันทึก PDF

รายละเอียดการทำงาน

GET /api/organization ดึงข้อมูลเกี่ยวกับรายละเอียดองค์การบริหารส่วนตำบล (อบต.)
BEARER AUTH
รายละเอียดการทำงาน

ดึงข้อมูลที่ตั้งหน่วยงาน อบต. และข้อมูลชื่อนายกองค์การบริหารส่วนตำบล เพื่อนำข้อมูลไปกรอกลงหัวฟอร์มเอกสารใบแจ้งหนี้และใบเสร็จรับเงินอย่างเป็นทางการ

Request Details
No request body required
Response Example
{
  "subdistrict_id": 1,
  "organization_full_name": "องค์การบริหารส่วนตำบลในเมือง",
  "district_name": "เมืองชัยภูมิ",
  "province_name": "ชัยภูมิ",
  "title_name": "นาย",
  "first_name": "สมศักดิ์",
  "last_name": "ใจดี",
  "phone_number": "044811000",
  "address_number": "99 ม.1",
  "village_id": 1,
  "village_number": 1,
  "village_name": "บ้านใหม่"
}
PATCH /api/organization ปรับปรุงข้อมูลติดต่อและผู้มีอำนาจลงนาม (นายก อบต.)
BEARER AUTH
รายละเอียดการทำงาน

บันทึกแก้ไขข้อมูลส่วนกลางขององค์กร เช่น ที่อยู่ หรือชื่อนายก อบต. เมื่อมีคำสั่งปรับเปลี่ยนโครงสร้างกำลังพล

Request Body (JSON)
{
  "title_name": "นาย",
  "first_name": "สมศักดิ์",
  "last_name": "ใจดี",
  "phone_number": "0811112222",
  "address_number": "99/1",
  "village_id": 1,
  "subdistrict_name": "ตำบลในเมือง",
  "district_name": "เมืองชัยภูมิ",
  "province_name": "ชัยภูมิ"
}
Response Example
{
  "message": "Organization updated successfully"
}
